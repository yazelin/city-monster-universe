# Cross-City Habitat Hypotheses

> **STATUS NOTE:** 本文件是 active working research，不是全部已確認的 ecology。Axis 的最新狀態以 `RESEARCH_LEDGER.md` 為準。

這份文件收納跨城市的生態軸與 mechanism candidates。它們不屬於任何單一 TW observation，也不自動等於 species。

## Current axis status

### TRANSITION DENSITY / 轉換密度
**Question:** 短距離／短時間內，需要切換多少套行動規則？

Current status: `ACTIVE HABITAT AXIS`  
Species link: `PROVISIONAL`

TW-001 / State Switching 與此高度相關，但不能直接等同 species。

### USE AMBIGUITY / 用途歧義
**Question:** 同一小塊空間是否同時或輪流承擔多種用途，需要持續協商？

Current status: `ACTIVE HABITAT AXIS`  
Species link: `PROVISIONAL`

TW-002 / Edge Reading 與此高度相關，但騎樓等形式只是可能載體，不是物種定義。

### PATH DEPENDENCE / 路徑依賴
**Question:** 已消失或改變的上一代用途，是否仍限制現在可以怎麼生活？

Current status: `ACTIVE RESEARCH / PROVISIONAL`

`OLD ≠ INHERITED`。地方很老不代表 Path Dependence 強。

### CLIMATE EXPOSURE / 氣候暴露
**Question:** organism 在 patch 中承受熱、光、雨、水分、風與 shelter distribution 的方式是否可獨立預測 behavior？

Current status: `CANDIDATE CROSS-CITY AXIS / UNCONFIRMED`

這是後來由 FN-007 壓力測試浮現的 candidate，加入本文件是為避免舊三軸模型看起來像封閉定論。

## Different time scales

目前仍值得保留的 working distinction：
- Transition Density：秒／分鐘尺度
- Use Ambiguity：小時／一天尺度
- Path Dependence：年／數十年尺度

這只是研究模型，不代表一 axis 一 species。

Climate Exposure 的時間尺度可能從瞬間事件到季節性暴露都有，因此暫不強迫塞入單一尺度。

## Interaction Model

`Habitat profile = active axes + candidate axes + shaping variables`

同一城市不同街區可以完全不同；不同城市可以非常相似。

> **City character is not a species generator. Habitat combinations are research conditions.**

## Species Gate

一個 habitat axis 不等於一個 species。Species hypothesis 必須依 `SPECIES_HYPOTHESIS_THRESHOLD.md` 通過門檻。

禁止：
- 一城市一 species
- 一 habitat axis 一 species
- 一個漂亮概念一 species
- 因已有 TW 編號而保護分類

## Legacy reinterpretation

## Evidence warning
