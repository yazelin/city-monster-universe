# Base Character Prompt

這份 prompt 是起點，不是固定咒語。每次先完成 `templates/city-research.md`，再把研究結果放進來。

```text
請以「[CITY]」為主題，設計一隻原創的擬人化城市小怪物。

核心人格：
「我覺得 [CITY] 像一個 [PERSONALITY SENTENCE] 的人。」

牠不是城市吉祥物，也不直接代表城市，而是一隻長期住在這裡、逐漸被當地環境與生活方式塑形的不明生物。

角色方向：
可愛、微怪、療癒、有一點慵懶感，像生活在城市裡很久的小居民。Q 版比例，頭大身小、短手短腳，表情簡單但有個性。可以擬人化，但不要完全像人類，也不要只是普通動物吉祥物。

最重要：
不要直接把著名地標、城市名稱、地圖輪廓放到角色頭上或身上；不要做成觀光宣傳吉祥物。請把城市特色轉譯成角色的身體、材質、服裝、姿態、表情與生活痕跡。

這座城市的創作素材：
- 天氣：[WEATHER]
- 城市節奏：[RHYTHM]
- 建築 / 街道材質：[MATERIALS]
- 自然環境：[NATURE]
- 生活習慣：[DAILY HABIT]
- 聲音 / 氣味 / 光線：[SENSES]
- 隱藏地方細節：[HIDDEN DETAIL]

請只挑選 3–5 個最有力量的元素轉化，不要全部塞入角色。

轉譯思考方式例如：
雨 → 濕潤、下垂、半透明或吸水後變重，而不是直接畫雨傘。
海 → 流動曲線、鹽分侵蝕與風化質感，而不是直接畫海浪。
老房子 → 磁磚、磨石子、鏽蝕、褪色油漆。
炎熱 → 曬褪色、暖色斑點、懶散姿態。
都市繁忙 → 快步、略疲倦的眼神、隨身小包。
山 → 穩定厚實的輪廓，而不是把山直接放在頭頂。

角色必須有：
- 一個明確人格
- 一個日常習慣
- 一個小缺點
- 一個可愛的小動作
- 3–5 個藏在造型裡的城市隱喻

視覺風格：
手繪 character concept art；溫暖米白紙張背景；水彩、色鉛筆、粉彩與舊印刷品混合質感；低飽和帶灰的大地色；細微磨石子、舊磁磚、褪色油漆等材質；線條不完全工整、有手作感；可愛但不要幼兒卡通感；有收藏型 designer art toy 的質感。

畫面以一隻完整角色為中心。設定稿版本可在周圍加入少量手繪箭頭、材質色票、小型姿勢草圖與簡短觀察註記。

不要過度塞滿元素。城市特色應該是「第一眼看到角色，第二眼才發現城市」。
```

## Quick prompt

如果只想快速發想，可以先使用：

```text
[CITY] 像一個 [PERSONALITY] 的人。請把當地的 [WEATHER]、[MATERIAL]、[DAILY HABIT] 與 [HIDDEN LOCAL DETAIL] 隱喻成一隻可愛、微怪、擬人但仍是不明生物的城市小怪物。不要直接使用地標、地圖或觀光 icon；第一眼是角色，第二眼才發現城市。
```
