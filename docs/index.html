OBSERVATION 00

我們不知道牠們從哪裡來。

只知道雨會留在牠們的皮膚裡，陽光會把顏色曬淡，老房子的磁磚、磨石子、鏽鐵與褪色油漆，住久了也可能變成身體的一部分。

所以我們不說「台北怪代表台北」。比較接近的說法是：牠在台北住太久了，身上開始長出台北。
