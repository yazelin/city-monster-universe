HOW TO READ THIS PAGE

城市不是物種邊界。

同一種生物可能在台北、台中、高雄或其他地方出現；同一座城市也可能同時存在很多 species。真正影響 encounter likelihood 的，是更細的 habitat patch、時間、氣候與生活使用方式。

因此這一頁記錄的是：目前在台北研究到什麼、哪些 habitat 值得繼續找、以及哪些舊判斷仍需要被推翻。

CONFIRMED REFERENCE · OBS-TW-0001

State Switching

早期觀察顯示，某類個體會持續讀取周遭移動軌跡，在人流、等待、通行或其他規則即將改變時，先做小幅偏移、收窄、減速或等待。

目前比較值得保留的不是「總是在趕時間」這種城市人格，而是對狀態轉換的敏感與適應。

LOCAL POPULATION NOTES

雨、灰綠與濕水泥還不是 species。

灰綠、米灰、乾濕交界、舊磁磚與潮濕表面仍可以保留，但目前只能視為 Taipei population morphology 的候選。

如果同一 species 在較乾、較熱或材質不同的 habitat 仍維持 State Switching，卻長成不同表面，反而會支持這個區分。

HABITAT PATCHES TO TEST

下一步不是找「更台北」的地方。

High Transition：大型轉乘節點、多模式交通與步行規則快速切換的區域。

Low Transition control：長時間維持單一生活規則、低轉乘需求的住宅型街巷。

High Use Ambiguity：市場邊緣、住商混合 threshold、騎樓／店前／停車／通行共用空間；用來測試 TW-002-like behavior 是否也在台北出現。

Path Dependence：舊 infrastructure 轉型後仍留下 corridor、尺度、土地形狀或邊界限制的區域。

LEGACY FIELD NOTE · NOT PRECISE DATA

Archive narrative fragment

在出口附近看到牠。大家都走得很快，牠也是。

前面的人掉了一張卡片。牠停下來撿了，追了十幾步才還給對方。

然後又繼續趕路。

這段早期文字保留作為創作與研究歷史，但因缺乏可驗證的 locality / time / conditions，不把「07:42 · 雨」之類細節偽裝成正式 Field Record data。

EXPECTED CROSS-CITY ENCOUNTERS

台北應該還會看到別的 species。

如果 Edge Reading hypothesis 成立，那麼台北高度 Use Ambiguity 的 habitat 也應該可能出現 TW-002-like organism。反過來，OBS-TW-0001 對應的 organism 也應該能在台中、高雄的高 Transition habitat 被找到。

這些目前都是 prediction，不是已確認分布。
