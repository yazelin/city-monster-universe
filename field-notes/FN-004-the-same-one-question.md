# Field Notes 004 — 我不知道是不是同一個

## 07:58

早上的入口只有一件事很清楚：大家都要通過去。

用途沒有什麼好爭的。

但每幾分鐘，走法就會改一次。

一批人出來，另一批人停下；門開了，路徑分開；門關了，原本讓出來的位置又被填滿。

我又看到那個變化。

它總是在真正的人流改向以前早一點發生。

不是很多。

大概只早到足以讓我懷疑，是不是我自己慢了一拍。

有三次，它先退出一條即將變擠的線。

第三次之後，我記下順序：

`停一下 → 偏離 → 人流改向 → 回到可通行區`

我沒有辦法記它長什麼樣。

這是規則。

### Archive annotation

**Habitat:** High Transition / Low Ambiguity  
**Observed sequence:** pause → leave previous trajectory → crowd shift → re-enter usable path  
**Candidate reading:** State Switching  
**Trace basis:** action sequence + slight anticipatory timing  
**Trace confidence:** LOW

## 14:26

下午我回到同一帶。

人少很多。

沒有一批一批的進出，也沒有突然重新分流。

可是旁邊的店開始把東西往外放。

一張椅子先出現。

後來多了一個箱子。

再晚一點，有台機車停在原本能直接走過的位置。

我看到一個東西停了一下。

接著往旁邊偏。

我差點立刻把它記成早上的那個。

因為順序很像。

但我等了很久，人流沒有改向。

真正改變的是那塊地方的用途。

它沒有回到原本的位置。

等椅子被搬進去以後，它才又靠近一點。

這一次比較像：

`停一下 → 退到未被占用處 → 等用途穩定 → 靠近新的邊界`

不是早上的順序。

### Archive annotation

**Habitat:** Low Transition / High Ambiguity  
**Observed sequence:** pause → withdraw from contested use → wait → approach new edge  
**Candidate reading:** Edge Reading  
**Trace link to morning:** possible, not established  
**Trace confidence:** LOW

## 18:11

我第三次經過。

早上的規則回來了一點。

下班的人開始增加，但店前的東西還沒完全收掉。

Transition 和 Ambiguity 同時升高。

我本來以為這次會比較容易確認。

結果完全相反。

每一個動作都可以有兩種解釋。

牠退開，是因為人要過來？

還是因為那塊地方正被重新占用？

牠停著，是在等人流？

還是在等用途穩定？

我甚至開始懷疑，早上和下午之所以看起來有連續性，只是因為我已經想找到連續性。

所以我沒有提高 TRACE-TP-001 的 confidence。

### Archive annotation

**Habitat:** High Transition / High Ambiguity  
**Identification value:** poor  
**Observer-bias risk:** HIGH  
**Decision:** do not strengthen trace

# Trace review

目前有兩種互相衝突的讀法。

### Interpretation A — same individual, mode switch

早上：State Switching-like mode  
下午：Edge Reading-like mode

如果成立，`ONE SPECIES / MULTIPLE MODES` 會得到重要支持。

### Interpretation B — different individuals / different organisms

我們只是因為兩者都會「停一下、偏開」而把它們連在一起。

如果 habitat 本來就會迫使許多 organism 做類似動作，這個 trace 幾乎沒有 identity value。

目前 Archive 選擇：

`TRACE-TP-001 = CANDIDATE / LOW CONFIDENCE`

不升級。

---

# The useful failure

這次最重要的結果不是「找到同一隻」。

而是發現：

> **停、退、讓、靠近，這些動作本身太普通，不能辨認 individual。**

下一輪若要提高 trace confidence，必須找到更不容易被 habitat 強迫產生的 residual behavior，例如：

- 在多個等價路徑中反覆選同一種次佳路徑
- 固定的反應延遲，而不是單純避讓
- 干擾後回到特定位置的順序
- 在沒有必要時仍重複某個 action sequence

也就是：

> **我們要找的不是牠怎麼適應環境，而是牠在適應之後，還留下了什麼屬於自己的偏差。**

那個偏差才可能是 individual trace。
