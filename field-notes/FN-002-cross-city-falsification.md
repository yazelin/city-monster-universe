# Field Notes 002 — 如果牠不是那座城市的

> **Phase:** TEXT-ONLY OBSERVATION  
> **Morphology:** LOCKED  
> **Purpose:** cross-city falsification  
> **Classification:** unresolved

這一組不再去新城市找新 organism。

相反地，我們把已經在某座城市形成的 hypothesis，故意放進另一座城市。

如果牠只能在「第一次被寫到的城市」成立，現有 taxonomy 就有問題。

---

## A — Taichung / 疑似 State Switching

月台上的人還沒有開始動。

樓梯口先動了。

不是人。

至少我第一眼沒有看到有人走過去。

幾秒後，車門開了。原本站成一片的人分成兩股，一股往門裡，一股讓出來。

剛才那個變化的位置，正好落在兩股人中間。

我跟著往前。

到了手扶梯前，大家又重新排成一列。

那個東西又比我們早一點到了旁邊。

它沒有趕在任何人前面。

比較像是每次規則要換以前，它就先離開上一個位置。

### Archive note

**Candidate mechanism:** State Switching  
**City:** Taichung  
**Prediction tested:** TW-001-like behavior should appear outside Taipei when Transition Density is high.  
**Result:** provisional support  
**Morphology evidence:** none  
**Alternative explanation:** crowd flow artifact / observer expectation

如果後續 observations 重複出現，這筆資料應擴張 State Switching candidate 的 range，而不是建立「台中版 TW-001」。

---

## B — Taipei / 疑似 Edge Reading

早上的騎樓只是一條路。

中午多了一排箱子。

下午有兩台機車停進來，其中一台把原本能直接走過去的位置切成兩半。

我第一次注意到牠，是因為有人推嬰兒車過來。

那個原本看起來已經沒有空間的位置，不知道什麼時候又多出一點餘裕。

嬰兒車過去以後，店員把箱子往外拖。

餘裕又不見了。

傍晚我再經過，同一塊地上擺了椅子。

我沒有再看到牠。

但那時候我突然不知道：如果牠真的還在，我應該往哪裡看？

因為早上、下午、傍晚的「邊緣」根本不是同一個地方。

### Archive note

**Candidate mechanism:** Edge Reading  
**City:** Taipei  
**Prediction tested:** TW-002-like behavior should appear outside Taichung when Use Ambiguity is high.  
**Result:** provisional support  
**Morphology evidence:** none  
**Alternative explanation:** ordinary rearrangement of objects / narrative projection

如果這種 behavior 只在 Taichung 被接受、在 Taipei 的相似 habitat 卻被忽略，Archive 可能存在 city-label bias。

## C — Kaohsiung / State Switching without a station

紅燈的時候，大家停在陰影裡。

綠燈亮了，人開始往前。

走到一半，前面的陰影結束了。

有人加快，有人往騎樓方向偏，有人照原本的速度走。

我注意到那個東西，是因為它沒有選任何一條固定路線。

它先跟著一群人往前，接著在大家開始分散以前停了一下。

下一次看到時，它已經在另一側的遮蔽裡。

這一次沒有車門、沒有月台、也沒有轉乘。

只有光、熱、號誌和人群一起改變了行動規則。

### Archive note

**Candidate mechanism:** State Switching  
**City:** Kaohsiung  
**Research value:** tests whether Transition Density must be transit-derived.  
**Result:** unresolved but important  
**Morphology evidence:** none

這筆如果成立，`Transition Density` 的定義必須保持比「交通轉乘」更廣：任何短時間內要求生命切換行動規則的 habitat 都可能成立。

# Interim result

FN-002 暫時支持一件事：

> **我們應該追蹤 mechanism 的 range，而不是城市角色的 range。**

但這三篇都只是 deliberately constructed literary tests，不是假裝存在的真實田野數據。

它們的用途是檢查世界觀是否在換城市後仍然自洽，並替未來真正的 observation protocol 提供可反證的問題。

---

# New pressure on the taxonomy

如果 State Switching 在 Taipei / Taichung / Kaohsiung 都可能出現，而 Edge Reading 也能跨城，那下一個真正困難的問題變成：

> **State Switching 與 Edge Reading 真的是兩種 organism，還是同一種更底層能力在不同時間尺度上的表現？**
