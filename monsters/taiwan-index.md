# Taiwan Series / 台灣城市小怪物

> 這些是可持續演化的角色 seed。原則不是「城市吉祥物」，而是觀察住在這裡會留下什麼痕跡，再讓痕跡長成生物。

## TW-001 — 台北種 / Taipei
**人格：** 總是在趕時間，看起來有點冷淡，其實很溫柔。
**材質 / 天氣 / 習慣：** 灰綠磁磚、濕氣與突然的雨；走得很快，即使沒有目的地也是。
**隱藏細節：** 身體總有一小塊像剛離開騎樓的乾濕交界。

## TW-002 — 台中種 / Taichung
**人格：** 看起來悠閒，其實非常在意生活品味。
**材質 / 天氣 / 習慣：** 曬暖的石材、午後柔光；喜歡找舒服的位置待很久。
**隱藏細節：** 配件永遠比實際用途講究一點。

## TW-003 — 高雄種 / Kaohsiung
**人格：** 被太陽曬得懶洋洋，講話直接，但非常好相處。
**材質 / 天氣 / 習慣：** 鹽蝕金屬、褪色漆面、強烈陽光與海風；白天慢，晚上精神變好。
**隱藏細節：** 身體邊緣像長期被風吹磨過。

## TW-004 — 宜蘭種 / Yilan
**人格：** 安靜、柔軟，已經把下雨當成日常背景音。
**材質 / 天氣 / 習慣：** 潮濕布料、水氣、稻田綠；喜歡聽雨而不是躲雨。
**隱藏細節：** 身體吸飽水時會變得更安靜。

## TW-005 — 花蓮種 / Hualien
**人格：** 話不多，看起來很安靜，但身體裡有很大的力量。
**材質 / 天氣 / 習慣：** 石材、風化表面、山海風；常停下來看很遠的地方。
**隱藏細節：** 身體重心很低，像在對抗比自己巨大很多的尺度。

## TW-006 — 台東種 / Taitung
**人格：** 不太趕時間，很會發呆，而且知道怎麼跟空間相處。
**材質 / 天氣 / 習慣：** 曬暖的土色、風與海氣；會花很久做看似什麼都沒做的事。
**隱藏細節：** 身體周圍總像多留了一點空白。

## TW-007 — 台南種 / Tainan
**人格：** 像住在老房子裡很久的老靈魂；很會吃、有點固執，卻會偷偷照顧你。
**材質 / 天氣 / 習慣：** 磨石子、舊磁磚、曬暖牆面；怕熱所以總往陰影與窄巷裡鑽。
**隱藏細節：** 身上有一小塊反覆修補、不同年代疊在一起的表面。
**避免：** 不直接使用古蹟、廟宇、牛肉湯等觀光符號。

## TW-008 — 新竹種 / Hsinchu
**人格：** 腦袋轉得很快，表面理性俐落，但永遠被風弄得有點狼狽。
**材質 / 天氣 / 習慣：** 霧面科技材料、玻璃、被風吹皺的薄布；走路會下意識壓住身上的東西。
**隱藏細節：** 輪廓永遠有一側被風吹歪，像身體正在修正方向。
**避免：** 不直接畫晶圓、科技公司 logo 或米粉。

## TW-009 — 基隆種 / Keelung
**人格：** 看起來陰沉難接近，其實很習慣替別人留一個避雨的位置。
**材質 / 天氣 / 習慣：** 濕混凝土、鏽蝕鐵件、港邊油彩；總在找屋簷、棚架與乾一點的角落。
**隱藏細節：** 身體不同區域乾燥速度不同，形成深淺水痕。
**避免：** 不靠雨傘、郵輪或港口地標直接辨識。

## TW-010 — 嘉義種 / Chiayi
**人格：** 不搶話、很耐心，表面樸素但對自己的節奏非常確定。
**材質 / 天氣 / 習慣：** 木頭、老漆、日曬後的暖色表面；下午容易停下來休息，喜歡慢慢把事情做完。
**隱藏細節：** 身上有細小年輪般的紋理，但不是直接畫樹。
**避免：** 不直接使用阿里山小火車或雞肉飯。

## TW-011 — 屏東種 / Pingtung
**人格：** 熱情、耐熱、生命力很強；看起來懶散，其實非常能撐。
**材質 / 天氣 / 習慣：** 被太陽曬軟的布、植物纖維、褪色塑料；會本能尋找風口和樹蔭。
**隱藏細節：** 身體向陽面與背陽面像兩種不同年齡。
**避免：** 不直接使用墾丁、椰子或海灘圖示。

## TW-012 — 桃園種 / Taoyuan
**人格：** 很會移動、適應力強，常像只是暫時停在這裡，卻默默記得很多人的來去。
**材質 / 天氣 / 習慣：** 行李箱磨痕、工業塑料、雨後柏油；習慣在等待與轉乘之間打瞌睡。
**隱藏細節：** 身上有多層貼過又撕掉的標記痕跡，暗示遷徙而非直接畫機場。
**避免：** 不直接使用飛機或航廈。

## TW-013 — 彰化種 / Changhua
**人格：** 務實、低調、很會照顧日常；不太展示自己，但總知道哪裡有好東西。
**材質 / 天氣 / 習慣：** 金屬加工痕、農地土色、被使用很久的工具表面；喜歡把東西修好而不是換掉。
**隱藏細節：** 身體上有幾個非常漂亮卻不刻意展示的修補接點。
**避免：** 不直接使用大佛、肉圓等符號。

## TW-014 — 南投種 / Nantou
**人格：** 慢熟、內向，很能自己待著；情緒像山裡的天氣，變化不一定先通知別人。
**材質 / 天氣 / 習慣：** 霧面石材、苔痕、潮濕木頭；常縮在自己舒服的小範圍裡觀察遠方。
**隱藏細節：** 表面在潮濕時浮出淡淡紋路，乾燥後又消失。
**避免：** 不直接畫日月潭輪廓或山峰帽子。

## TW-015 — 雲林種 / Yunlin
**人格：** 很接地氣、耐心，對季節與時間的感覺比時鐘準。
**材質 / 天氣 / 習慣：** 乾土、農用網布、日曬塑料；會依照風、溫度與氣味調整每天的行動。
**隱藏細節：** 身上的色澤會像田地一樣隨季節變深變淺。
**避免：** 不直接畫農產品或廟會符號。

## TW-016 — 苗栗種 / Miaoli
**人格：** 有點害羞、有點倔強，喜歡熟悉的人事物，但其實對細節非常敏感。
**材質 / 天氣 / 習慣：** 陶土、木質、丘陵草色；習慣收藏小東西並放在固定的位置。
**隱藏細節：** 身體表面有像手工窯燒形成的不均勻色差。
**避免：** 不把桐花直接當頭飾或花紋主體。

## TW-017 — 澎湖種 / Penghu
**人格：** 被風吹到什麼都看開了；外表粗糙，性格卻非常明亮。
**材質 / 天氣 / 習慣：** 風蝕石、鹽霧、曬白表面；站著時總會自然把身體壓低迎風。
**隱藏細節：** 所有突出部位都像被風磨圓了一點。
**避免：** 不直接使用雙心石滬、玄武岩柱或海鮮。

## TW-018 — 金門種 / Kinmen
**人格：** 警覺、節制、記性很好；不輕易說過去的事，但身體全部記得。
**材質 / 天氣 / 習慣：** 花崗岩、風化牆面、鏽金屬；會反覆確認門窗與周遭聲音。
**隱藏細節：** 表面有被覆蓋過的舊痕跡，只在特定角度看得到。
**避免：** 不直接使用軍事設施、砲彈或戰地標語作為造型噱頭。

## TW-019 — 馬祖種 / Matsu
**人格：** 安靜、耐風、很會等待；像一直知道遠方有人會回來。
**材質 / 天氣 / 習慣：** 花崗岩、海霧、舊牆灰；天黑後比白天活躍，喜歡靠近微弱的光。
**隱藏細節：** 身體暗處偶爾出現非常淡的冷光，不直接畫成藍眼淚。
**避免：** 不把藍眼淚做成明顯特效或觀光 icon。

## TW-020 — 新北種 / New Taipei
**人格：** 很難用一句話說完，因為牠擅長在不同生活圈切換人格；可靠、耐走、很會通勤。
**材質 / 天氣 / 習慣：** 河岸水泥、山邊濕氣、老公寓磁磚與郊區金屬；每天移動很遠，回家後立刻縮成一團。
**隱藏細節：** 身上不同區塊像來自不同棲地，但已磨合成同一個身體。
**避免：** 不硬塞單一地標來概括幅員很大的城市。

## Collection rule

編號代表「被記錄的順序」，不是行政地位或排名。同一城市未來可以出現亞種，例如 `TW-001A 台北雨季種`、`TW-001N 台北夜行種`；角色定稿前仍應依 `templates/city-research.md` 做更深入的實地／記憶觀察。
