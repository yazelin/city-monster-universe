# City Monster Universe / 城市小怪物宇宙

> **Collect the creatures that cities leave behind.**

城市小怪物宇宙是一個持續收集城市痕跡的角色創作計畫。

這些生物不是城市吉祥物，也不直接「代表」一座城市。牠們只是長期生活在某個地方，久而久之，被那裡的雨、陽光、濕度、街道、建築、交通、食物氣味、生活速度與人的習慣慢慢塑造成現在的樣子。

第一眼，應該先看到一隻有個性的奇怪生物；第二眼，才逐漸發現牠為什麼屬於那座城市。

## 核心公式

**一座城市 → 一種人格 + 一種身體材質 + 一種天氣 + 一個生活習慣 + 一個隱藏的地方細節。**

城市元素不是裝飾，而是角色形成的原因。

## 創作原則

- 不把知名地標直接插在角色頭上。
- 不依賴城市名稱、地圖輪廓或觀光 icon 讓人辨識。
- 不做成典型官方吉祥物。
- 優先描繪城市的日常，而不是景點。
- 將城市特色轉譯成身體、材質、服裝、姿態、表情與生活痕跡。
- 保持可愛、微怪、療癒、略帶慵懶的不明生物感。
- 角色可以擬人，但不要完全變成人類，也不要只是普通動物擬人。
- 城市感最好是「看第二眼才發現」。

## 未來

Taiwan Series 只是第一層。未來可以自然延伸到 Tokyo、Hong Kong、Bangkok、Seoul、New York 等城市，也可以出現：

- 同城市不同生活圈的亞種
- 雨季 / 夏季 / 冬季型態
- 日行與夜行型態
- 搬家後逐漸混合兩座城市特徵的個體
- 已消失街景留下的稀有種

這個 repository 是設定集，也是田野筆記。先記錄，再創作；讓每一隻怪物都有理由長成牠現在的樣子。
