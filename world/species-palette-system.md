# Species Palette System / 物種配色系統

> 城市不決定怪物的顏色；怪物長期生活留下的痕跡，決定牠的顏色。

City Monster Universe 的每個 Field Record 共用同一本田野圖鑑的結構，但每一物種擁有自己的「視覺氣候」。配色不是城市 logo，也不是觀光印象色，而是從氣候、材質、生活習慣、磨損、光線與時間留下的痕跡取樣。

## Rules

1. **Trace before color** — 先描述生活痕跡，再選顏色。
2. **Material before symbol** — 從混凝土、布、金屬、土、石、漆面等材質取色，不直接從地標或名產取色。
3. **Atmosphere, not skin tone** — palette 同時影響角色與 Field Record UI，但不要求怪物全身都是主色。
4. **Shared skeleton** — 所有頁面保留一致的版面、字體層級、Field Record 結構與收藏系統。
5. **Species climate** — 可變部分包含紙張底色、細線、標籤、stamp、選取色、局部污漬、插圖襯底與互動 accent。
6. **Restraint** — 每種以 5–6 個核心色為上限；避免高飽和觀光宣傳感。

## UI token mapping

Each Field Record should expose these semantic tokens rather than hard-code city colors:

```css
--species-ink
--species-shadow
--species-primary
--species-secondary
--species-surface
--species-paper
```

The palette should be noticeable through accumulation, not through a single loud hero color. A reader moving between species pages should feel that the weather changed while the field guide remained the same book.
