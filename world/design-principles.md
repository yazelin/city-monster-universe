# Design Principles / 角色設計原則

## 1. Character first, city second

第一眼必須是一隻成立的角色，而不是城市元素拼貼。拿掉城市名稱後，牠仍然要有人格、輪廓與記憶點。

## 2. Metaphor, not landmark

不要直接使用地標作為辨識捷徑。把城市特色轉譯成角色本身。

例如：

- 雨 → 濕潤、下垂、半透明、吸水後變重
- 海 → 流動曲線、鹽分侵蝕、風化質感
- 老房子 → 磁磚、磨石子、鏽蝕、褪色油漆
- 炎熱 → 曬褪色、暖色斑點、懶散姿態
- 都市繁忙 → 小包、快步、略疲倦的眼神
- 山 → 厚實、安定、沉著的輪廓

## 3. Anthropomorphic, but still unknown

角色可以穿衣、拿東西、等車、散步、發呆，但不要完全變成人類。

基本方向：

- Q 版比例，頭大身小
- 短手短腳
- 簡單但有個性的表情
- 可愛、微怪、療癒、略慵懶
- 保留「不知道是什麼生物」的空間
- 避免普通貓狗等動物直接擬人

## 4. Daily life over tourism

比起「這座城市最有名什麼」，優先問：

- 這裡的人怎麼等車？
- 雨來的時候大家怎麼走？
- 下午的光是什麼顏色？
- 哪些東西被太陽曬到褪色？
- 巷子裡聞起來像什麼？
- 人們走路快還是慢？
- 哪種材質摸起來最像這座城市？

## 5. One hidden discovery

每隻至少留一個不立即解釋的地方細節。它可以是一塊材質、一條線、一個配件或一個習慣，讓熟悉城市的人第二眼才認出來。

## 6. Visual language

系列基礎視覺語言：

- 溫暖米白紙張背景
- 水彩 + 色鉛筆 + 粉彩 + 舊印刷品混合質感
- 低飽和、帶灰的大地色
- 磨石子、舊磁磚、褪色油漆等細微紋理
- 手工、不完全工整的線條
- 可愛但避免幼兒卡通感
- 帶有收藏型 designer art toy 的存在感
- 設定頁可使用少量箭頭、色票、姿勢草圖與手寫觀察註記

## 7. Restraint

不要把所有研究到的城市元素都塞進一隻角色。

每次挑 3–5 個最有力量的隱喻即可。留白也是系列的一部分。

## Test

完成一隻角色後問：

1. 不寫城市名，我還會喜歡這隻角色嗎？
2. 它是不是靠地標才能被認出？如果是，重新設計。
3. 熟悉這座城市的人，是否可能在第二眼得到一個「啊，原來是這個」的發現？
4. 它看起來真的像在這裡生活過，而不是穿著這座城市的 cosplay 嗎？
