## Important

TW-003 不是「高雄種」。這個 ID 先代表第三組 Field Archive observation。

本輪問題不是：

> 高雄應該長出什麼怪物？

而是：

> **高雄的生活環境中，有沒有 TW-001 `STATE SWITCHING`、TW-002 `EDGE READING`，甚至可能的 `CONTEXT READING` 都解釋不了的穩定生存壓力？**

在找到之前，不建立第三個 species morphology。

---

## 01. Existing Models Already Explain a Lot

### Transition habitat

高雄並不是 TW-001 的天然反例。環狀輕軌串連捷運與港區，多個站點本身就是轉乘與城市活動節點；未來軌道路網也持續以 TOD、轉乘與多模式交通整合發展。

因此「轉乘」「交通切換」「人流」不能直接拿來建立 TW-003。

### Ambiguous edge habitat

高雄也不是 TW-002 的天然反例。高雄騎樓管理規範明確涉及公共通行、商業活動與一定寬度的行人空間；機慢車停放規範也允許部分騎樓在不妨礙通行下停放。

因此「騎樓」「停車」「店面」「公共／私人模糊」也不能直接拿來建立 TW-003。

---

## 02. First Candidate Beyond Existing Matrix — LEGACY CONVERSION

目前最值得研究的新方向不是港口 icon，也不是陽光，而是：

> **同一塊大型城市基礎設施，在功能退場後並沒有消失，而是被新的生活重新佔據。**

高雄環狀輕軌大量沿用舊臨港線路廊；官方說明也直接把舊鐵道路權、鐵道文化保存、新軌道與都市空間活化放在同一套轉型中。高雄港站亦同時處理文化景觀保存、開放空間與 TOD 開發。

這與 TW-002 的 `Use Ambiguity` 不完全相同。

TW-002 問：

> **這塊地方現在可以拿來做什麼？**

TW-003 candidate 問：

> **當一個地方原本的巨大用途消失之後，新的生命如何在舊結構留下的尺度、方向與記憶中生活？**

暫稱：

`LEGACY CONVERSION / 遺構轉用`

或更生態化地描述：

`INHERITED INFRASTRUCTURE / 繼承式棲地`

目前只是一個 **HABITAT HYPOTHESIS**，不是 species mechanism。

---

## 03. Why This Might Be Different

`STATE SWITCHING` 處理的是短時間內規則切換。

`EDGE READING` 處理的是同一空間當下用途的協商。

`LEGACY CONVERSION` 若成立，處理的是另一個時間尺度：

> **城市幾十年尺度的功能退場與重新使用。**

可能 sequence：

`INDUSTRIAL / LOGISTIC FUNCTION → ABANDONMENT OR RELEASE → PRESERVATION → PUBLIC REUSE → NEW DAILY LIFE`

這不是「今天早上／晚上用途不同」，而是**城市記憶本身成為 habitat structure**。

---

## 04. Candidate Shaping Variables

### LEGACY DEPTH

一個地方保留多少上一代用途的結構、方向、尺度與材質。

### FUNCTIONAL DISCONTINUITY

舊用途與新用途差異有多大。例如貨運鐵路 → 輕軌／公園／文化空間。

### REUSE INTENSITY

新生活是否真的長期進入舊結構，而不是只把它保存成展示物。

### MEMORY VISIBILITY

居民是否仍能從軌道、倉庫、碼頭、地景或空間尺度感覺到「這裡以前是別的東西」。

### CLIMATE / EXPOSURE

高雄的熱、日照、海風與開放尺度可能塑造 population morphology，但目前不能拿來當 species identity。

---

## 05. Falsification Questions

要讓 `LEGACY CONVERSION` 有資格成為新 species hypothesis，至少必須回答：

1. 這種 habitat 是否會產生 TW-001 / TW-002 無法解釋的穩定 behavior？
2. 如果把歷史遺構完全移除，只留下新的公園／道路，behavior 是否消失？
3. organism 是在讀「現在的用途」，還是在利用「舊用途留下的身體尺度」？
4. 同樣機制是否也會出現在台北鐵道遺構、台中舊工業空間、其他港市？
5. 若跨城市也成立，它是否是一種 `legacy-adapted species`，而非高雄限定種？
6. 高雄只是觀察證據特別密集，還是真的形成不同 population pressure？

---

## 06. Strong Negative Controls

以下不能作為 TW-003 species evidence：

- 港口本身
- 船、貨櫃、吊車造型
- 高雄很熱
- 陽光很強
- 海風
- 輕軌
- 工業感
- 大尺度道路
- 「南部比較悠閒」之類城市人格

這些都只能是研究入口或 population shaping variable。
